# 📚 AI PDF Study Assistant

AI PDF Study Assistant is an AI-powered web application that transforms PDF documents into an interactive learning experience. Built with **Python**, **Streamlit**, and **Google Gemini**, it allows students to upload study materials and interact with them using natural language.

## ✨ Features

* 📄 Upload and analyze PDF documents
* 💬 Ask questions about the uploaded PDF
* 📚 Generate concise summaries
* 🧩 Create AI-generated quizzes
* 🃏 Generate study flashcards
* 📌 Extract key points automatically
* 💭 Interactive chat interface with conversation history
* ⚡ Fast responses powered by Google Gemini

## 🛠️ Technologies Used

* Python
* Streamlit
* Google Gemini API
* PyPDF2
* python-dotenv

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/AI-PDF-Study-Assistant.git
cd AI-PDF-Study-Assistant
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Create a `.env` file and add your Google Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

Run the application:

```bash
streamlit run app.py
```

## 📖 How to Use

1. Upload a PDF document.
2. Ask questions about its content.
3. Use the AI tools to:

   * Generate a summary
   * Create quizzes
   * Generate flashcards
   * Extract key points
4. Continue chatting with the AI to better understand your study material.

## 🎯 Project Purpose

This project was developed as a personal learning initiative to explore **Generative AI**, **Large Language Models (LLMs)**, and modern AI application development. It demonstrates how AI can enhance learning by turning static PDF documents into intelligent study assistants.
